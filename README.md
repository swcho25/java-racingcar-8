# java-racingcar-precourse
## 기능 목록
### 1. 입력 기능
- [x] 경주할 자동차 이름 입력
- [x] 경주 반복할 횟수 입력
### 2. 경주 진행 기능
- [x] 사용자의 수만큼 랜덤 수 얻기 (0~9 사이)
- [x] 랜덤 수가 4 이상인 사용자의 자동차를 한 칸 전진
- [x] 위의 과정을 입력 받은 수만큼 반복 진행
- [x] 우승자 판별 (최대 거리 기준, 동점자 모두 우승)
### 3. 출력 기능
- [x] 진행 횟수 별 실행 결과 출력
- [x] 우승자 안내 문구 출력 (여러 명이면 쉼표로 구분)
### 4. 예외 처리 기능
- [x] 경주할 자동차 이름이 잘못 입력된 경우
  - 이름이 5자를 초과
- [x] 반복할 횟수가 잘못 입력된 경우
  - 양의 정수 값이 입력되지 않은 경우
- [x] 값이 입력되지 않았거나 공백인 경우
